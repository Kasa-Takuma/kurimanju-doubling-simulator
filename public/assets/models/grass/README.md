# Grass Medium 01

The grass model and 1K textures in this directory come from Poly Haven's
[Grass Medium 01](https://polyhaven.com/a/grass_medium_01) asset.

- License: [CC0 1.0](https://polyhaven.com/license)
- Source model: `grass_medium_01_1k.gltf`
- Units: metres
- Downloaded for the web build on 2026-09-10

The source asset is used without changing its geometry. The application
selects several grass clumps from the distributed glTF and instances them at
the measured metre scale.
